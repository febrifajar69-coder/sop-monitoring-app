⚙ Pengaturan Koneksi Google Apps Script API

Status Pembacaan Data Saat Ini:

Aplikasi ini sudah langsung terhubung untuk membaca data live dari Spreadsheet 1 (RAW, SOP LEMBAR1) dan Spreadsheet 2 (AJS, AYU, FIK, WBN, OTHER). Agar tombol "Kirim ke Monitoring" dan "Simpan Follow Up" dapat menulis langsung ke baris Google Spreadsheet Anda dari Vercel/HP/PC, tempelkan URL Web App Apps Script di bawah ini:

Tips: Setelah disimpan, URL ini tersimpan di perangkat Anda. Anda juga bisa memasukkannya di file config.js (bagian APPS_SCRIPT_URL) sebelum push ke GitHub/Vercel agar seluruh HP SA langsung terhubung otomatis.
Panduan Di Mana & Cara Paste Script API (Tanpa Menghapus Script Lama):
  1. Buka salah satu Google Spreadsheet Anda (misal Spreadsheet 1 - Form Order).
  2. Klik menu Extensions (Ekstensi) → Apps Script di bagian atas.
  3. TIDAK PERLU menghapus kode lama: Cukup lihat panel sebelah kiri (Files), klik tanda + (Add a file) → Script, lalu beri nama WebAppAPI.
  4. Salin kode dari file google-apps-script/WebAppAPI.gs di folder proyek ini (atau klik tombol Salin Kode Script API di bawah), lalu paste ke dalam file WebAppAPI.gs tersebut dan tekan Ctrl + S.
  5. Klik tombol biru Deploy → New deployment di kanan atas Apps Script.
  6. Pilih jenis Web app:
    • Execute as: Me (Email Anda)
    • Who has access: Anyone (Siapa saja)
  7. Klik Deploy, salin Web app URL yang muncul, lalu tempelkan pada kolom di atas.
